# coffeeShop2
Qwen Coder咖啡电商项目部署指南

# 1. 打开终端（命令行），进入项目目录
cd 你的项目文件夹

# 2. 安装依赖（首次需要，会生成 node_modules 文件夹）
npm install

# 3. 启动开发服务器
npm run dev

然后浏览器会自动打开（或手动访问）：
开发模式：http://localhost:5173
生产模式：先 npm run build，然后 npm run preview
